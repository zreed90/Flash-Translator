Flash - A Layman's Translator — Chrome Extension
An intuitive, interactive Google Chrome Extension that translates complex, technical, or academic writing into crystal-clear layman's terms, everyday analogies, and background context with an emergent 3D animated assistant.

Features
Emergent 3D Brain Assistant: Hovers and tracks your cursor on any webpage or PDF.
Triple-Click Relocation: Move the assistant anywhere on your screen.
Collapsible Chat & Sleep Animation: Minimizing the chat puts a 3D sleep mask over the brain's eyes with hovering Z's while preserving your session.
Interactive Notepad & Writing Animation: Save highlighted chat takeaways directly to an in-extension ruled notebook with pencil writing and page-flipping animations.
Secure Cloud Backend: All AI requests route through a secured AWS Lambda proxy. No API keys or server credentials exist in this extension package.
Installation
Download / Clone this repository:

git clone https://github.com/your-username/Flash-Translator-1.git
(Or click Code -> Download ZIP and extract it).

Load in Chrome:

Open Google Chrome and navigate to chrome://extensions/.
Enable Developer mode using the toggle switch in the top-right corner.
Click Load unpacked in the top-left corner.
Select the repository folder (the folder containing manifest.json).
(Optional) Enable PDF Support:

In chrome://extensions/, click Details on the extension card.
Toggle on Allow access to file URLs so the extension can explain local downloaded PDFs (file:///).
